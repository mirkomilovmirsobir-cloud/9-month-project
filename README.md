# SmartMarket website

Files:
- `index.html` — the whole page (design, sections, modals)
- `styles.css` — all styling, including the dark and light themes
- `main.js` — products, cart, wishlist, forms, theme toggle and animations

## Run it locally
Keep the three files in one folder and open `index.html` in a browser.
No installation needed.

## What was updated
- Full redesign (dark aurora theme) with animations and creative details
- A light/dark theme switch in the header (remembered in the browser)
- New product photos, cleaner mobile layout, confetti on checkout
- The hero is now an electronics vitrina: a lit display shelf with a row of gadgets, side arrows, drag to spin and automatic rotation

## Deploy
The site is published on Vercel from the `main` branch. Every push to `main`
starts a new production build.
